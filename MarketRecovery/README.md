# Разрушенные рынки — Act 2 Recover

Результат уже применён и сохранён в `Assets/Scenes/Act 2 Recover.unity`.

- **Разрушенный рынок 1:** умеренные беспорядки; два опрокинутых прилавка, рассыпанные товары, часть торговли оставлена на месте.
- **Разрушенный рынок 2:** сильное разрушение; шесть опрокинутых прилавков, товары и тара на земле.
- **Разрушенный рынок 3:** разграбленный рынок; два опрокинутых прилавка, пустые ящики, скрытая часть мелких товаров и редкие остатки на прилавках.

Использованы существующие модели. Корни рынков, родители объектов, масштабы и ссылки на компоненты сохранены. Изменения записаны как переопределения экземпляров в этой сцене.

## Управление в Unity

Меню **Tools → TIF → Markets**:

- **Apply Three Ruined Layouts** — повторно применяет три композиции из `Layouts.json`, начиная с сохранённого исходного расположения, и сохраняет только целевую сцену. Команда поддерживает Undo.
- **Restore Original Layout** — восстанавливает Transform и видимость объектов из `OriginalTransforms.json`. Затем сохраните сцену (`Ctrl+S`). Команда поддерживает Undo.
- **Inspect Act 2 Recover** — записывает отчёт об иерархии.

Настройки в Inspector не требуются. Инструмент не добавляет игровых компонентов.

Editor-скрипты: `Assets/Editor/MarketRecoveryTool.cs` (меню, анализ и восстановление) и `Assets/Editor/MarketRecoveryComposition.cs` (размещение и проверка геометрии).

`OriginalTransforms.json` содержит исходные состояния объектов, включая идентификаторы Unity. `Act 2 Recover.before.unity.txt` — полная резервная копия сцены перед изменениями. Для выборочного восстановления рынков используйте команду меню: она сохраняет последующие изменения остальных объектов сцены.

`Result.json` содержит измеренные расстояния и результаты проверки геометрии. `Previews/market-1.png`, `market-2.png`, `market-3.png` показывают композиции при диагностическом освещении; освещение самой сцены не изменялось.
