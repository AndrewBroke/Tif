# Окровавленное полено

Созданы пять текстур: брызги (`01_Splashes`), размазанные следы (`02_Smears`), потёки (`03_Drips`), засохшая кровь (`04_Dried`), сильное окровавливание (`05_Soaked`).

Готовый префаб: `Assets/Sprites/Textures/Окровавленное полено/Полено_Окровавленное.prefab`.

Рядом находятся пять материалов `BloodyLog_*.mat`. Компактные текстуры `512 × 256` лежат в подпапке `Textures`, отдельный меш с новой UV-развёрткой — `Meshes/BloodyLog_Compact.asset`.

## Изученный исходник

- Префаб: `Assets/Models/1 Act/Полено (1).prefab`.
- Меш: `Cylinder.002` из `MainHouse_FirstAct.fbx`, 456 вершин, 236 треугольников.
- Материал: `Props`, шейдер `Universal Render Pipeline/Lit`.
- Исходный атлас: `MainHouse_FirstAct.fbm/Props.png`, 1500 × 1500.
- Боковые UV-острова: U ≈ 0.1622–0.3578, V ≈ 0.3578–0.4860, жёлто-оливковая древесина с продольными волокнами.
- UV торцов: U ≈ 0.5252–0.5823, V ≈ 0.0487–0.1068, общий рисунок годичных колец. Перекрывающиеся UV используют один и тот же рисунок крови.

## Создание и проверка

Использован встроенный `image_gen`, пять отдельных редактирований исходных участков. Полные промпты: [Generation-prompts.txt](Generation-prompts.txt).

Участки древесины и торцов вырезаны из пяти готовых атласов и упакованы в `512 × 256` без масштабирования. Боковой участок 320 × 220 размещён с координат (8, 16), торцы 144 × 144 — с (352, 56), отсчёт от нижнего левого угла. Для фильтрации добавлен отступ 8 пикселей с повторением края. UV перенесены на отдельную копию меша; геометрия, нормали, тангенты и остальные UV сохранены.

Проверены 455 680 пикселей участков всех пяти вариантов — отличий от исходных текстур нет. Максимальная ошибка переноса UV меньше 0.000008 пикселя. SHA-256 восьми исходных файлов (FBX, его `.meta`, исходный префаб, материал, атлас и их `.meta`) не изменились. Новый префаб не зависит от исходного FBX и общего атласа. Полный результат: [Compact-validation.json](Compact-validation.json).

Импорт Unity: Default texture, sRGB, 512 × 256, Point, mipmaps включены, без сжатия, Clamp. Крупные варианты 1500 × 1500 заменены компактными, GUID текстур сохранены. Превью созданы на новом меше с двух сторон в изолированном рендере, без изменения сцены: [Preview.png](Preview.png).

## Unity Inspector

1. Перетащить `Полено_Окровавленное.prefab` в сцену.
2. В `Mesh Renderer → Materials → Element 0` назначить любой из пяти материалов рядом с префабом. По умолчанию выбран `BloodyLog_01_Splashes.mat`.

Новый префаб сохраняет масштаб и поворот исходного полена; позиция обнулена. Изменять исходный `Props` или FBX не требуется.
