# Медик-преследователь

1. Выполнить **Tools > TIF > Medic > Create Chaser Assets**. Команда создаёт `Assets/Prefabs/Medic Chaser.prefab`, контроллер и зацикленные копии клипов в `Assets/Animations/Medic Chaser`. Повторный запуск сохраняет уже существующие ассеты.
2. Поставить префаб на запечённый NavMesh. Agent Type должен совпадать с NavMeshSurface; для Act 2 используется тип 0. Существующую поверхность менять не нужно.
3. На игроке должен быть `PlayerHealth` и тег `Player`. Если поле **Player** пустое, `ProximityChaser` перебирает активные объекты с тегом `Player` и выбирает первый с компонентом `PlayerHealth` на том же объекте. Если игрок появляется позже, поиск повторяется раз в секунду. После обнаружения поиск прекращается. При нескольких подходящих объектах назначить нужный явно. Коллайдеры игрока должны находиться на объекте с `PlayerHealth` или ниже по иерархии.
4. В `PlayerHealth` назначить Animator объекта Hit Volume, чтобы урон воспроизводил постобработку.

В `ProximityChaser`:

- **Initial Animation**: `Run`, `Walk`, `Crawl`, `Idle`. На старте выбирается случайный кадр этой анимации и воспроизведение останавливается. При активации та же анимация продолжается с этого кадра.
- **Animation State Override**: необязательный полный путь состояния для другого контроллера, например `Base Layer.MyRun`. Это позволяет использовать компонент с другими персонажами и анимациями.
- **Activation Distance**: дистанция начала преследования. После активации персонаж продолжает преследовать игрока и за пределами этой дистанции.
- **Movement Speed** и **Animation Speed**: скорость движения и воспроизведения независимо друг от друга.
- **Contact Damage**: урон за одно соприкосновение, по умолчанию 1. Пока коллайдеры игрока остаются внутри триггера, повторного урона нет. После выхода всех коллайдеров и нового входа урон наносится снова.
- **Repath Interval**, **Nav Mesh Sample Radius**: частота обновления пути и радиус поиска точки игрока на NavMesh. При неполном или отсутствующем пути персонаж останавливается и повторяет попытку.

Префаб содержит NavMeshAgent, CapsuleCollider с Is Trigger и кинематический Rigidbody без гравитации. В Physics Layer Collision Matrix должны быть разрешены контакты слоёв игрока и медика. Если меняется форма персонажа, подогнать капсулу и размеры агента в Inspector. Не подключать к нему одновременно другие скрипты движения или Seller, управляющий тем же Animator.

При смерти `PlayerHealth` один раз вызывает пустой виртуальный метод `PlayDeathAnimation()`, затем событие **On Death**. Анимацию падения можно добавить в этот метод позже. Преследователи останавливаются, когда игрок мёртв.

Проверка в Play Mode: вне радиуса медик замер; внутри радиуса продолжает анимацию и идёт по NavMesh; первый контакт снимает 1 HP; удержание контакта не снимает дополнительные HP; три отдельных контакта приводят к 0 HP.
